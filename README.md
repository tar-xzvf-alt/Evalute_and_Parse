# ParseVK — сбор и анализ региональных новостей VK

Приложение для исследователя региональной экономики: выбрать сообщества, собрать публикации за нужный год и сохранить воспроизводимый корпус для дальнейшего анализа.

**Два способа работы:** графическое окно (GUI) и командная строка (CLI). Они используют общие правила оценки активности и выбора источников.

## Что уже умеет проект

| Возможность | Где доступна |
|---|---|
| Поиск сообществ, оценка постов за год, проверка месячного покрытия | Новый экран GUI и CLI |
| Ручной набор источников, автоматический выбор по активности | GUI; в CLI — профиль, явные ID и команда `select` |
| Сбор нужного года без последовательного чтения всех более новых лет | Новый сбор GUI/CLI |
| Сохранение и повторный запуск набора сообществ и параметров | Общие JSON-профили GUI/CLI |
| Исходные тексты, Excel и паспорт сбора | GUI и CLI |
| Продолжение после ошибки с проверкой и переиспользованием завершённых источников | GUI «Продолжить…» и CLI `--resume` |
| Получение токена через браузер со скрытым вводом итогового URL | CLI `auth login`, без запуска GUI |
| Словарная тональность КартаСловСент/RuSentiLex | Вкладка анализа и отдельные скрипты |
| Прежний сбор комментариев | Вкладка «Прежний сбор» |
| Классификация по 17 целям устойчивого развития (ЦУР, SDG) | Отдельный скрипт и внешняя TensorFlow-модель |

**Пока не реализованы как единый процесс:** LLM-разметка, обучение новой модели оценки экономических событий и исследование связей с Росстатом из GUI/нового CLI. Имеющиеся аналитические скрипты не равнозначны готовой автоматической исследовательской системе.

## Быстрый старт: окно приложения

На Linux из корня проекта:

```bash
bash scripts/setup_gui_env.sh  # установка один раз
bash run_gui.sh               # обычный запуск
```

Будет создано `.venv-gui` с зависимостями из `requirements-gui.txt`. Для чёткого текста нужен системный Tk с Xft: в исходном `myenv` обнаружена сборка без сглаживания шрифтов. Старое окружение не изменяется.

В приложении откройте «API Токен», затем «Сбор новостей». Сначала найдите источники, проверьте годовую активность и только потом запускайте выгрузку.

Подробнее: [первый запуск и типичные затруднения](docs/getting-started.md), [работа с GUI](docs/vk-collection.md).

## Быстрый старт: командная строка без окна

Если `.venv-gui` уже установлен, используйте его Python. Для сервера достаточно минимального окружения:

```bash
python3 -m venv .venv-cli
.venv-cli/bin/python -m pip install -r requirements-cli.txt
.venv-cli/bin/python -m parsevk --help
```

Сохраните пользовательский ключ VK API в `vk_token.txt` в корне проекта. Ключ не нужно вставлять в команду или публиковать в Git.

```bash
.venv-cli/bin/python -m parsevk search \
  --query "Омск новости" --limit 20 --output candidates.json

.venv-cli/bin/python -m parsevk assess \
  --input candidates.json --year 2019 --output assessed.json
```

Это только поиск и оценка, **не скачивание корпуса**. Для полного процесса, автоотбора и запуска сохранённого профиля: [инструкция CLI](docs/cli.md).

На Windows используйте Python своего окружения (`.venv-cli\Scripts\python.exe`); инструкция установки есть в [руководстве первого запуска](docs/getting-started.md).

## Что сохраняется и что означают результаты

- **Профиль** — выбранные источники и параметры. Позволяет собрать те же сообщества за другой год.
- **Оценка активности** — предварительное число доступных записей по найденным границам года; в GUI показано `≈`.
- **Проверенный подсчёт** — результат полного обхода периода, с количеством по месяцам.
- **Корпус** — публикации: исходные тексты в JSONL, отфильтрованные тексты с метаданными в Excel.
- **Паспорт запуска** — JSON с параметрами, источниками, количествами, файлами и статусом выполнения.

Оценка активности не измеряет число экономических новостей. Поиск по названию сообщества не гарантирует региональную принадлежность каждого события. Периоды нового сборщика задаются в **UTC**, начало года включено, начало следующего исключено. Считаются доступные записи владельца стены, включая его репосты; удалённые и недоступные записи восстановить нельзя.

Сохраняйте рабочие корпуса, например, в `data/raw/`: этот каталог не попадает в Git. Перед использованием результатов проверьте статус паспорта (`complete` — завершено; `failed`/`cancelled` — неудача/отмена).

## Анализ и модели

Словарная тональность и SDG-классификация — **разные задачи**. Существующая модель RuBERT относит тексты к ЦУР, а не заменяет будущую модель оценки благоприятности экономического события.

Для TensorFlow 2.10.1 требуется отдельное окружение **Python 3.10**, зависимости — `requirements02022026.txt`. Модель `rubert_bert_RU_35data_6_epochs/` распространяется отдельно и в Git не включена.

Ограничения старых скриптов, входные данные и запуск: [анализ и совместимость](docs/analysis.md).

Для новой задачи подготовлен отдельный **экспериментальный PyTorch RuBERT baseline**: фильтр публикаций и модель оценки/тем. Это не старая SDG-модель и не готовая функция GUI/CLI сбора. Подготовка Windows-ПК, групповые разбиения, запуск и временные оценки — в [руководстве обучения](docs/rubert-training.md). Машинные метки пока предварительные; наличие кода обучения не подтверждает качество классификаторов.

## Проверки

```bash
.venv-gui/bin/python -m unittest discover -s tests -v
```

Тесты сбора и CLI работают без настоящего токена и сети. Без графической среды тест окна пропускается. Для минимального окружения можно использовать `.venv-cli/bin/python` с той же командой.
