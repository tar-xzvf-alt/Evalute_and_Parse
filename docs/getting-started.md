# Первый запуск ParseVK

## 1. Выберите способ работы

| Задача | Что использовать |
|---|---|
| Выбрать источники в таблице, оценить архив, сохранить профиль | GUI, окно приложения |
| Повторять сбор, запускать по SSH или проверять автоматически | CLI, командная строка |
| Применить старую TensorFlow-модель ЦУР | Отдельное окружение Python 3.10 |

GUI и CLI сбора не требуют установки TensorFlow. Окружения можно держать рядом: `.venv-gui`, `.venv-cli`, старое `myenv`.

## 2. Установите окружение

### Linux: GUI

Нужны системный Python с модулями `venv`, `tkinter` и доступ к графической сессии. Выполните из корня репозитория:

```bash
bash scripts/setup_gui_env.sh
bash run_gui.sh
```

Скрипт использует `/usr/bin/python3`. При необходимости другой интерпретатор задаётся так:

```bash
GUI_PYTHON=/путь/к/python3 bash scripts/setup_gui_env.sh
```

На проверенной системе ALT системный Tk использует Xft (сглаживание), а Tk старого `myenv` — X11 без сглаживания. Это свойство сборки Tk, его нельзя исправить одной заменой семейства шрифта. Если текст выглядит пиксельным, запускайте через `bash run_gui.sh`, а не напрямую через старое окружение.

Текущее общее окно импортирует старый словарный анализ уже при запуске: первый старт может потребовать загрузки стоп-слов NLTK. Поэтому для минимального окружения без библиотек анализа используйте CLI, а не GUI.

### Linux/сервер: только CLI

```bash
python3 -m venv .venv-cli
.venv-cli/bin/python -m pip install -r requirements-cli.txt
.venv-cli/bin/python -m parsevk --help
```

Для сбора нужен Python 3.10 или новее, сеть и пользовательский ключ VK. Графическая сессия и Tk не нужны.

### Windows

Используйте установленный Python с поддержкой `venv`; для GUI — с Tk (обычно входит в официальный установщик). В PowerShell из корня проекта:

```powershell
py -m venv .venv-gui
.\.venv-gui\Scripts\python.exe -m pip install -r requirements-gui.txt
.\.venv-gui\Scripts\python.exe src\TryToParse_new.py
```

Для CLI вместо `requirements-gui.txt` можно установить `requirements-cli.txt`, затем запустить `-m parsevk --help`. Linux-скрипты `.sh` на Windows не обязательны. Точное отображение GUI на Windows требует отдельной проверки; текущие проверки выполнялись на Linux.

## 3. Подготовьте ключ VK

Нужен **пользовательский ключ VK API**, которому доступны поиск сообществ и чтение стен. Сервисного ключа недостаточно для `groups.search`.

- В GUI: вкладка «API Токен», поле ввода и кнопка сохранения.
- В CLI: файл `vk_token.txt` в рабочей директории, переменная `VK_TOKEN` или `--token-file путь`.
- В файле должна быть только строка ключа, без кавычек и `access_token=`.
- Не отправляйте ключ в чат, не добавляйте его в профиль и Git. Старые опубликованные ключи следует заменить.

Получить/обновить ключ без GUI можно командой `python -m parsevk auth login` в своём интерактивном терминале. Она открывает тот же браузерный OAuth-flow, принимает полный итоговый URL скрытым вводом и сохраняет токен без вывода секрета. Для SSH есть `--no-browser`. Вход и подтверждения остаются в браузере; это не автоматическое продление. Подробности и безопасное хранение — в [руководстве CLI](cli.md#получить-или-обновить-токен-без-gui).

Наличие файла ещё не означает действующий доступ. Проверить ключ на нужной операции можно небольшим поиском:

```bash
.venv-cli/bin/python -m parsevk search \
  --query "Омск новости" --limit 1 --output candidates.json
```

В старой вкладке есть кнопка получения токена со ссылкой на OAuth. Она использует прежний способ авторизации; не считайте эту ссылку гарантированно актуальной. Способ получения ключа проверяйте по действующим правилам VK.

## 4. Выполните первый сбор

### Через окно

1. Откройте «Сбор новостей».
2. Введите запрос и год; начните с небольшого числа кандидатов.
3. Нажмите «Найти сообщества».
4. Отметьте источники в первом столбце и нажмите «Оценить выбранные».
5. При необходимости выполните «Уточнить + месяцы» — это полный обход периода, он дольше оценки.
6. Сохраните профиль, выберите существующую папку и нажмите «Собрать выбранные».

В CLI тот же процесс описан в [cli.md](cli.md). Не забывайте: `search` и `assess` не создают корпус, для выгрузки нужны `collect` или `run`.

## 5. Проверьте результат

Откройте паспорт `collection_*.json`, убедитесь в статусе `complete`. Сверьте количества и файлы по [контрольному списку](pilot-checklist.md). Для повторного года загружайте тот же профиль и изменяйте год, а не запускайте новый поиск автоматически.

## Частые затруднения

| Признак | Что проверить |
|---|---|
| `No module named ...` | Команда запущена Python нужного окружения? Установлены его зависимости? |
| `no display name` / ошибка `DISPLAY` | Для сервера используйте CLI; GUI требует графическую сессию |
| Пиксельный текст и неровные рамки | Новое окружение с Tk/Xft и `run_gui.sh`; не старый Tk/X11 |
| Ошибка VK 5 | Ключ отклонён; проверьте актуальность и способ получения |
| Ошибка VK 15 или недоступная стена | Проверьте права ключа и доступ к конкретному источнику; ошибка не равна нулю постов |
| В результате `≈ 0` за старый год | В доступной выдаче не найден период; это не доказывает, что постов никогда не было |
| Ошибка восстановления стены | Допустимые сдвиги проверяются автоматически до трёх раз; неподтверждённое изменение остаётся ошибкой. Для повторения только незавершённых источников используйте «Продолжить…» или `--resume` |
| CLI вернул код 4 | В JSON есть ошибки источников; не используйте частичный результат как полный |
| Нет файлов после поиска | Поиск/оценка не выполняют сбор; запустите `collect` или `run` |

Прежде чем присылать сообщения об ошибках, уберите токены и URL с секретными параметрами.
