# Сбор новостей VK

Запуск из корня репозитория:

```bash
bash scripts/setup_gui_env.sh  # один раз
bash run_gui.sh
```

## Читаемость и окружение GUI

Интерфейс использует светлый фон, тёмный текст и оранжевые акценты в духе BaseALT; это не официальная тема компании. Основные действия выделены цветом, вспомогательные — нейтральными кнопками. Семейство выбирается из реально доступных: Noto Sans/DejaVu Sans на Linux, Segoe UI на Windows, Helvetica на macOS. Основной размер — 18 пикселей, заголовок — 28; окончательный вид зависит от Tk и DPI.

В исходном `myenv` обнаружен Tk 9 с `fontsystem=x11` вместо Xft: он даёт пиксельные шрифты независимо от выбранного семейства. Системный `/usr/bin/python3` в проверенном ALT-окружении использует Xft. `setup_gui_env.sh` создаёт `.venv-gui` на нём; старое окружение Python 3.10 остаётся для TensorFlow. Путь можно переопределить через `GUI_PYTHON`. Окружение использует доступные системные Python-пакеты (`--system-site-packages`), недостающие устанавливаются только в venv.

`run_gui.sh` выбирает `.venv-gui`, иначе — старое `myenv` с предупреждением. При запуске через старое окружение цвета и геометрия обновятся, но сглаживание шрифтов этим не исправляется. Рамки рисуются через `polygon_shapes`, без зависимости от специального шрифта значков CustomTkinter.

## Новый экран «Сбор новостей»

1. Введите токен на вкладке «API Токен» или сохраните его в `vk_token.txt`.
2. Укажите запрос и год. Границы нового экрана — UTC: начало года включено, начало следующего исключено. Это явное правило первой версии, а не автоматическое определение часового пояса региона.
3. Задайте M кандидатов (1–1000), K выбранных источников и минимальный порог N публикаций.
4. «Найти кандидатов» получает паблики из `groups.search`. В ручном режиме отметьте строки в столбце «Сбор» и нажмите «Оценить выбранные».
5. «Уточнить + месяцы» проходит весь выбранный год, считает записи и месячное покрытие. Двойной щелчок по строке показывает месячные количества. Заголовок «Постов за год» сортирует строки по убыванию.
6. «Автоподбор заново» проверяет уже показанных кандидатов и заменяет отметки. Режим «Автоматически» запускает такой отбор сразу после нового поиска.
7. Выберите папку и нажмите «Собрать выбранные». Сбор не запускает новый поиск или автоматический отбор.

Предварительные количества обозначены «≈». Автоподбор уточняет значения около N (в пределах max(10, 10% N)), а также все потенциально проходящие источники. Это дороже оценки по границам, зато проходные места не ранжируются только по оценке. Выбирается до K источников, прошедших N; при равенстве — меньший ID. Ошибки доступа не считаются нулём. Месячное покрытие не является условием отбора.

Считаются доступные записи владельца стены (`filter=owner`), включая его репосты; это не число только тематических новостей. Фильтр текста применяется при экспорте: буквальные фразы без учёта регистра, через запятую — ИЛИ, пустое поле — все тексты; минимум слов проверяется отдельно. В отличие от старой реализации это не стемминг и не регулярные выражения.

## Профили

«Сохранить профиль» записывает JSON: параметры поиска/сбора, ID, названия и отметки сообществ. Ключи доступа и результаты измерения в профиль не попадают. «Загрузить профиль» восстанавливает набор без сетевого поиска и включает ручной режим. Можно изменить год и собрать те же источники. Переподбор выполняется только явной командой пользователя.

## Результаты

- `VK_<ID>_<год>_посты_<время>.xlsx`: отфильтрованные тексты, ID публикации и сообщества, дата UTC и ссылка. Первая колонка `text` с заголовком совместима с `read_excel()` в словарном анализе. Текстовые ячейки записываются как строки, а не формулы.
- `VK_<ID>_<год>_<время>.jsonl`: исходные тексты всех просмотренных публикаций периода до фильтрации, ID и timestamp. Сохраняет полные тексты, в том числе превышающие ограничение Excel 32767 символов.
- `collection_<время>.json`: паспорт запуска с периодом, фильтрами, источниками, количеством записей, файлами, числом API-запросов и статусом `complete`, `failed` или `cancelled`.

Отмена прекращает работу между запросами; текущий HTTP-запрос имеет таймаут 25 секунд. На отменённом/неудачном запуске JSONL может быть частичным; готовые файлы предыдущих источников сохраняются. Проверяйте статус паспорта, прежде чем считать корпус полным.

## Ускорение и границы надёжности

`WallPeriod` ищет границы по смещениям и затем читает только нужный участок. Для недавнего периода границы могут находиться сразу в первой странице. Закреплённая запись учитывается отдельно, даты фильтруются полуоткрытым интервалом. Проверяются порядок страниц, повторы ID, длина страниц и изменение общего количества записей.

VK не предоставляет снимок стены: одновременные удаления/публикации могут сдвигать offset. Проверки обнаруживают распространённые изменения, но не гарантируют обнаружение всех перестановок при неизменном count. При обнаруженной нестабильности операция завершается ошибкой и требует повторного запуска. Бинарный поиск опирается на убывающий порядок незакреплённых записей; это проверено на тестовых данных и ограниченно на живом API, не доказано для всех стен VK.

«Прежний сбор» сохранён для совместимости и комментариев. Получение постов в нём также использует новый поиск периода; интерфейс и прочая логика старого процесса не переработаны полностью.

## Проверки

```bash
.venv-gui/bin/python -m unittest discover -s tests -v
```

Тесты не используют токен и сеть. Проверяют соответствие последовательному отбору, границы и закрепление, месяцы, большой offset, изменения стены, отмену, ранжирование, профили и экспорт.
